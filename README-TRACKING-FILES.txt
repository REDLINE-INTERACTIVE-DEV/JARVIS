JARVIS tracking files

- VERSIONS.md: index and rules for independent platform tracking
- CHANGELOG-MOBILE.md: Android-only release history
- CHANGELOG-PC.md: Windows PC-only release history

All files belong in the repository root, next to README.md.

Every release record must include the actual full commit SHA, workflow run URL, artifact name, inspected test results, changes, and known issues. Never guess missing values. A CI artifact is not automatically a tested release.
